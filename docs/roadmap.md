# 八周路线图

> 这份路线图回答三个问题：**学什么、按什么顺序学、学到什么程度算过关**。
> 每天的具体内容在 [`docs/week-XX/day-XX.md`](.)，总表见 [schedule.md](schedule.md)。

## 1. 目标与定位

目标岗位：**AI 应用工程师 / AI 全栈工程师**——在模型之上构建产品与系统的人，而不是训练模型的人。

能力模型收敛为五个动作：

1. 工程化地调用大模型 API（流式、结构化、工具调用、重试、成本）
2. 用 RAG 把私有知识接进模型（分块、检索、重排、溯源）
3. 用 Agent 把"一次问答"升级为"多步任务"（ReAct、状态机、记忆）
4. 用评估与可观测证明系统"可信"（评估集、LLM-as-judge、链路追踪）
5. 用 FastAPI + Docker 让作品"可被访问"

不需要：模型训练、微调数学、深度学习理论推导。应用岗不考这些，时间要投给上面五件事。

## 2. 六大模块与验收标准

| 模块 | 核心内容 | 过关标准 |
| --- | --- | --- |
| M1 Python 工程 | uv/venv、类型注解、Pydantic、asyncio、httpx | 独立写出带类型注解、异常处理、异步请求的 CLI 工具 |
| M2 LLM API 与提示词 | 流式、采样参数、结构化输出、Function Calling、多模态、提示词四模式 | 产出生产级 `llm_client.py`，能为具体任务设计并迭代提示词模板 |
| M3 RAG | 嵌入、分块、向量库、混合检索、重排、溯源 | 手写 mini-RAG，再用框架实现知识库问答，能说清每处取舍 |
| M4 Agent 与 MCP | ReAct、LangGraph、记忆、MCP 协议、多智能体 | 3 工具 Agent + 可被客户端调用的 MCP Server |
| M5 评估与可观测 | 评估集、LLM-as-judge、RAGAS、Langfuse/LangSmith | 产出一份量化评估报告（命中率、忠实度、延迟、成本） |
| M6 部署与工程化 | FastAPI、SSE、Docker、云部署、降本 | 项目 API 化 + 公网可访问 demo |

## 3. 四阶段

```
基础切换          RAG 专项            Agent 专项          整合上线
W1 ── W2   →   W3 ── W4     →     W5 ── W6     →     W7 ── W8
Python+API      手写→框架           ReAct→LangGraph     评估+部署+作品集
     ↓               ↓                   ↓                   ↓
llm_client.py    mini-RAG → M2       Agent 骨架 → MCP      M3 + 上线 + 投递
```

| 周 | 主题 | 周末产出 |
| --- | --- | --- |
| W1 | Python 工程化 + LLM API 原生调用 | `shared/llm_client.py` |
| W2 | 提示词工程 + 多模态 + 晨报升级 | **M1 · 智能资讯简报 v2** |
| W3 | RAG 基础链路（无框架手写） | `mini_rag/`（≈200 行纯手写） |
| W4 | RAG 框架实战 + 知识库项目 | **M2 · 领域知识库问答** |
| W5 | Agent 基础 + LangGraph | 多工具 + 记忆 Agent 骨架 |
| W6 | MCP 协议 + 多智能体 | **MCP Server ×1** + M3 架构设计 |
| W7 | 评估 + FastAPI 服务化 + 部署 | **M2 公网 API** + 评估报告 |
| W8 | 毕业项目整合 + 求职冲刺 | **M3 · Agentic 应用** + 作品集 |

## 4. 每日时间结构（5h）

| 时段 | 内容 | 规则 |
| --- | --- | --- |
| 09:00–11:30 | 理论输入 | 边看边敲，禁止只看不写 |
| 14:00–16:30 | 动手实战 | 卡点先记录，限时 30 分钟自查 |
| 20:00–21:00 | 复盘沉淀 | 费曼式笔记：能不能讲清楚 |

在职转型可整体降速为"隔天推进"，即 16 周，内容不变。

## 5. 执行纪律

- **先原理后框架**：W3 手写 RAG、W5 手写 Agent，之后再用框架。框架月月翻新，链路不变。
- **以产出收口**：每周问一句"这周产出能进简历吗"。不能，就砍课程、保项目。
- **时间盒**：单点卡壳 > 30 分钟 → 记录、跳过、求助，回头再啃。
- **留痕**：每天在 `logs/day-XX.md` 写三行——今天学了什么、卡在哪、明天第一件事。

## 6. 每周自检（周末 30 分钟）

- [ ] 本周代码能独立跑通（不是复制粘贴跑通）
- [ ] 能不看书讲清本周 3 个核心概念
- [ ] `logs/` 有 5 天记录，`docs` 里的思考题有自己的答案
- [ ] 产出已提交到本仓库（commit message 写清"做了什么"）
- [ ] 落后 ≤ 1 天：正常；落后 ≥ 2 天：砍掉本周非核心阅读，保项目
