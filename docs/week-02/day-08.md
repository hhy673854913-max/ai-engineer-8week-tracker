## 上午 09:00–11:30 · 理论输入

### 1. 思维链（CoT）：不是万灵药

有效场景：多步推理、算术、逻辑判断、需要权衡的决策。
无效甚至有害：简单抽取、格式转换、分类（模型会开始"编理由"）。

三种写法：

```text
# 1) 零样本
让我们一步一步思考。

# 2) 结构化思考字段（推荐用于工程）
先填写 analysis：引用原文中的 2 个证据，说明你的判断依据；
再填写 result：结论 + 置信度（high/mid/low）。

# 3) 少样本 CoT（示例里带推理过程）
Q: ... 
A: 因为材料提到 X，所以结论是 Y。
```

**工程上优先选 2**：思考过程是字段，可校验、可丢弃、可审计；而自由文本思考过程只能给人看。

### 2. 少样本（Few-shot）：示例决定输出分布

三个原则：
1. **同构**：示例的字段、粒度、语气必须和期望输出一致。
2. **覆盖边界**：至少一个"信息不足 → 输出 null"的示例，否则模型学会"永远有话说"。
3. **顺序有偏**：模型对最后几个示例更敏感（近因效应）。把最想强调的放最后。

反模式：示例里给的答案比任务实际需要的更详细 → 模型会跟着啰嗦，输出变长、成本上升。

### 3. 自洽性（Self-Consistency）：用采样换准确率

同一问题采样 N 次（温度 > 0），对结果投票/取众数。适合有唯一答案的判断类任务：

```python
answers = [classify(text) for _ in range(5)]
final = Counter(answers).most_common(1)[0][0]
```

代价是 N 倍成本与延迟。**只在"错了代价很高、且答案可投票"的地方用**，比如合规风险判定，而不是摘要。

### 4. 结构化模板：把 prompt 当代码管理

```python
# code/week02/prompts/extract_v2.py
VERSION = "v2.1"
CHANGELOG = "v2.1: 增加 credibility 维度；v2.0: 增加 analysis 字段"

TEMPLATE = """你是资深财经编辑。从下面的资讯原文中抽取结构化信息。

规则：
1. 只依据原文，原文没有的信息填 null，不要推测；
2. credibility 从 0-100 打分，评分依据：信源权威性(40) + 信息可验证性(30) + 内容具体性(30)；
3. analysis 用两句话说明打分依据，必须引用原文片段。

输出 JSON：
{
  "analysis": "string",
  "title": "string，不超过 30 字",
  "summary": "string，不超过 80 字",
  "entities": ["string，公司/产品/人物"],
  "category": "融资 | 产品 | 政策 | 技术 | 其他",
  "credibility": 0,
  "tags": ["string"]
}

原文：
<article>{text}</article>
"""
```

模板管理三条：**版本号 + 变更记录 + 变量白名单**（渲染时缺变量要报错，不要静默填空字符串）。

### 5. 一个容易被忽略的成本

CoT + few-shot 会显著增加**输入 token**。如果每天要跑 500 条资讯，模板每多 200 token，一天就多 10 万 token。
所以模板迭代也要看"准确率提升 / 成本增加"的性价比，不是越复杂越好。

### 任务 2 · 迭代到 v2（60 min）

2. 加 2 个 few-shot 示例（其中一个是"信息不足 → null"）

### 任务 3 · 自洽性实验（30 min）

对 `credibility` 做 5 次采样，观察分数方差。如果方差 > 15 分，说明评分标准不够可执行，
需要把"信源权威性"拆成具体的信源清单（官方公告 40 / 权威媒体 30 / 自媒体 10）。

### 任务 4 · 模板渲染器（40 min）

```python
def render(template: str, **kwargs) -> str:
    missing = [k for k in re.findall(r"{(\w+)}", template) if k not in kwargs]
    if missing:
        raise ValueError(f"缺少模板变量: {missing}")
    return template.format(**kwargs)
```

**不要用 `str.format` 裸调**：缺变量会 `KeyError`，但如果模板里有 JSON 的花括号 `{}` 就会直接炸。
要么用 `$var` 风格 + `Template`，要么把 JSON 示例里的花括号转义。这是实战里必踩的坑，今天先踩掉。
