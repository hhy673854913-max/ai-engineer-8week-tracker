# Day 39 · 简历重写与模拟面试

> W8 · 周四 ｜ 5h ｜ 产出 两版简历 + 模拟面试记录 ｜ [Day 38](day-38.md) · [Day 40](day-40.md)

**今日目标**
- 把 11 年前端经验 + 3 个 AI 项目，重写成"AI 应用工程师"叙事
- 用 STAR-M 结构准备 3 个项目故事（Situation / Task / Action / Result / Metric）
- 完成一轮模拟面试自测，找出 3 个最容易被问穿的点

**验收**：两版简历（AI 全栈向 / AI 应用向）各一页；模拟面试 20 题有书面答案。

## 上午 09:00–11:30 · 方法

### 1. 简历的三处改动

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| 摘要 | "11 年前端，熟悉 Vue/React" | "11 年工程经验，近 1 年交付 3 个 AI 应用：RAG 知识库、Agentic 活动助手、智能简报" |
| 技能栏 | Vue/React/TS 放最前 | Python / RAG / LangGraph / MCP / FastAPI 放前，前端转为"全栈基础" |
| 项目栏 | 前端项目为主 | 3 个 AI 项目在前，2 个前端项目作工程能力佐证 |

**核心叙事**：不是"前端转 AI，从零开始"，而是"11 年工程能力 + AI 应用交付能力"的复合型候选人。

### 2. 成果量化的写法

| 弱写法 | 强写法 |
| --- | --- |
| 做了一个 RAG 问答系统 | 领域知识库问答：50 条评估集 hit-rate@5 0.86，P95 2.1s，单次成本 ¥0.003 |
| 用 AI 提升了活动搭建效率 | Agentic 活动助手：需求到页面骨架 22 秒，人工修改 2 小时，交付周期 3 天 → 1 天 |
| 熟悉 Agent 开发 | 4 工具 Agent + MCP Server ×2，接入 Claude Desktop 与自研 LangGraph Agent |

**每个项目至少一个数字**，没有数字的项目会被认为"没做过"。

### 3. 两版简历的差异

| | AI 全栈向 | AI 应用向 |
| --- | --- | --- |
| 强调 | 前端体验 + AI 能力结合 | RAG / Agent / 服务化链路 |
| 项目排序 | M2 界面 → M3 → M1 | M3 → M2 → M1 |
| 技能栏重点 | Vue/React + SSE + 可视化 | Python + LangGraph + 评估 |
| 目标 JD | AI 全栈、AI 产品前端 | AI 应用工程师、Agent 工程师 |

### 4. STAR-M：项目故事的骨架

```text
S 背景：4399 运营活动交付周期 3 天，瓶颈在页面搭建与素材准备
T 任务：用 AI 把交付压到 1 天，且质量不能降
A 行动：设计四角色流水线（解析/素材/生成/检查），接入 MCP 复用简报与知识库
R 结果：交付周期 3 天 → 1 天，单活动节省 2 人天
M 度量：20 次生成一次通过率 65%，代码可运行率 92%，单次成本 0.2 元
```

**准备 3 套**，分别对应 M1/M2/M3。每套练到 2 分钟内讲完。

### 5. 面试高频问题（自测用）

| 主题 | 问题 |
| --- | --- |
| RAG | 完整链路？分块怎么选？检索不准怎么排查？幻觉怎么缓解？引用怎么做？ |
| Agent | ReAct 原理？工具失败怎么办？多智能体何时优于单 Agent？ |
| MCP | 解决什么问题？与 Function Calling 区别？ |
| 评估 | 怎么建评估集？LLM-as-judge 的坑？上线怎么监控？ |
| 工程 | 流式怎么实现？成本怎么控？缓存策略？重试设计？ |
| 项目 | 架构取舍？最难的 badcase？重来会怎么改？ |

**答法**：先给结论（1 句）→ 再给做法（2–3 句）→ 最后给数据或反例（1 句）。

## 下午 14:00–16:30 · 实战

### 任务 1 · 写两版简历（90 min）

一页纸，结构：

```
姓名 | 求职意向 | 联系方式 | GitHub | 博客
一句话摘要
核心技能（分组，AI 在前）
项目经历（3 个 AI + 2 个前端）
工作经历（11 年，压缩到 4–5 条）
教育 / 证书（PMP）
```

### 任务 2 · 模拟面试 20 题（80 min）

对着上面的题库，**口述并录音**，然后回听。三个检查点：
- 有没有"嗯、那个"超过 3 次
- 有没有一句话超过 30 秒
- 有没有数字

把答不好的 3 题写下来，明天重点补。

### 任务 3 · 反问环节准备（20 min）

准备 3 个反问，体现你在评估对方：
- "团队现在的 AI 应用处在哪个阶段：POC 还是已上线？"
- "评估体系是谁在负责？"
- "这个岗位半年内最重要的一个交付是什么？"

### 任务 4 · 自我介绍 90 秒版（20 min）

```text
我是洪恒洋，11 年前端工程经验，近一年专注 AI 应用落地。
做过三个项目：一个领域知识库 RAG（hit-rate 0.86）、一个 Agentic 活动搭建助手（交付周期 3 天→1 天）、
一个多信源智能简报（日处理 100+ 条，零人工干预）。
我的优势是既能做 AI 链路，也能把产品体验做好——这是 AI 全栈岗位最缺的。
```
